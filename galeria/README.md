# JL Fotografia — Galeria no Google Drive

Esta versão mantém as fotos no Google Drive e deixa no GitHub apenas HTML, CSS, JS e os IDs/links das imagens.

## Galerias configuradas
- Casamento — Leonice & Euclides: 221 fotos
- Aniversário — Conrado: 239 fotos

## Estrutura
- `index.html`
- `config.js` — dados das duas galerias e links do Google Drive
- `assets/app.js` — login, paginação de 20 fotos, favoritos, lightbox e downloads
- `assets/style.css`
- `.gitignore` — impede envio acidental de galerias e vídeos pesados

## Importante
Os arquivos do Drive precisam permanecer compartilhados de forma que o navegador consiga visualizá-los pelo link.
Não é necessário colocar nenhuma pasta de fotos dentro do GitHub.
